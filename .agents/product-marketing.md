## Product Overview

**One-liner:** Автоматический журнал сделок для активного трейдера MOEX — запись, на которой проверяется ремесло.

**What it does:** МААТТ ведёт дневник трейдера за пользователя. Подтягивает сделки из Тинькофф через Invest API (read-only, 60-секундная синхронизация) или из CSV/Excel-выгрузки любого MOEX-брокера. На свечах MOEX ISS считает MAE/MFE, Trade Replay и 30+ статистических метрик (Optimal f, SQN, Sortino, Calmar, Profit Factor, R-Expectancy, Recovery Factor, Risk of Ruin, Monte Carlo 10 000, Z-Score, Tail Ratio, GHPR, Post-Exit). Двенадцать детерминированных эвристик размечают типовые ошибки (FOMO-вход, ранний выход, превышение размера позиции, торговля против сетапа). Полноценный AI-разбор — в roadmap, на лендинге показывается мелким бейджем «скоро».

**Product category:** Journaling & analytics SaaS для активных трейдеров фондового рынка РФ. По JSON-LD — `SoftwareApplication`, `applicationCategory: FinanceApplication`.

**Product type:** Web-приложение (Next.js 14 + FastAPI). Stack: Python 3.11, FastAPI, SQLAlchemy, PostgreSQL (с миграции SQLite), Next.js App Router, Tailwind. Хостинг — Yandex Cloud / Selectel (требование 152-ФЗ). PWA — в roadmap Q4 2026, native mobile — backlog.

**Business model:** Freemium SaaS, B2C-продукт с потенциалом B2B (Corporate-тариф для проп-команд через 6–12 мес).
- **Free** — 0 ₽: до 50 сделок в месяц, 1 счёт, базовые метрики (P&L, Win Rate, Profit Factor), импорт CSV/Excel, ручной ввод. FIFO: старые сделки вытесняются.
- **Pro** — 399 ₽/мес или 3 990 ₽/год (-17 %): безлимит сделок, до 5 счетов, MAE/MFE из MOEX, Trade Replay, эвристический разбор, Optimal f / SQN / Monte Carlo, расширенные метрики (Ulcer, K-Ratio, Sterling, Omega, Sharpe, Sortino, Calmar), Тинькофф API sync, экспорт CSV/PDF.
- **Corporate** — индивидуально: multi-account, cohort analysis, white-label отчёты для инвесторов, SSO/SCIM, SLA 99,9 %.

Конверсионное действие лендинга — регистрация на Free (без карты, 21 день Pro в подарок).

## Target Audience

**Target profiles (B2C — здесь «companies» = типы трейдеров):**
1. Активный ритейл-трейдер фондового рынка MOEX (P1, primary).
2. Проп-трейдинг команда из 3–10 трейдеров (P2, secondary, через 6–12 мес).
3. Любопытный новичок до 1 года стажа (P3, виральный, не платит).

**Decision-makers:** Не применимо для B2C primary — решение принимает сам трейдер. Для P2 — менеджер проп-команды (он же платит).

**Buying personas:**
- P1 (primary buyer) — трейдер сам себе ICP и платящий пользователь.
- P2 — менеджер команды; покупает через виральный путь (один из его трейдеров уже на Pro) или cold-outreach.
- P3 — не платит, но рекомендует через Smart-Lab/YouTube, когда вырастет в P1.

**Primary use case:** Я закрыл сделку — МААТТ автоматически считает её R, MAE, MFE, Post-Exit, маркирует против чек-листа из 12 правил и добавляет в общий журнал. В конце недели я открываю дашборд и вижу: что повторяется, где стоп слишком далеко, где я выхожу из страха, какой Optimal f у моей текущей системы. Каждый квартал я сравниваю себя с собой, не с рынком.

**Jobs to be done:**
1. **Видеть свои сделки в цифре, а не «по ощущениям».** Перестать спорить с памятью.
2. **Найти системную ошибку.** Не «эта сделка не зашла», а «я систематически теряю по пятницам» / «мой средний MAE убыточных в 1.5× дальше стопа».
3. **Сравнивать себя с собой.** Квартал к кварталу: вырос Optimal f, упал ли SQN.
4. **Перенести учёт сделок из Excel в фон.** Чтобы не тратить вечер пятницы на ручной ввод.
5. **Иметь свидетельство своего ремесла.** Запись как акт дисциплины, не как отчётность.

**Use cases (конкретные сценарии):**
- Подключение Тинькофф Invest API в день регистрации; первая статистика — через 2 минуты.
- Импорт CSV из БКС/Финама/Альфы (нативные коннекторы Финам/БКС — в roadmap Q2/Q3 2026).
- Просмотр Trade Replay вчерашней худшей сделки — со свечами вокруг входа/выхода и маркерами stop/take.
- Открытие MAE/MFE-страницы перед пересмотром стоп-лосс-методики.
- Еженедельный обзор: Optimal f, SQN, Risk of Ruin, Tail Ratio.
- Экспорт PDF-отчёта инвестору (Pro/Corporate).
- Календарный взгляд на P&L по дням недели — чтобы найти «дни-убийцы».

## Problems & Pain Points

**Core problem:** Активный трейдер MOEX теряет деньги по системным причинам, которые не видит. Память врёт, эмоции искажают разбор, Excel-журнал слишком ручной, чтобы вестись регулярно, а Тинькофф «Аналитика» показывает только агрегаты постфактум — без MAE, без MFE, без качества системы, без вероятности слива. В результате трейдер «гадает», вместо того чтобы «считать».

**Why alternatives fall short:**
- **Excel / Google Sheets шаблоны.** Гибко, но ручной ввод убивает дисциплину; нет автоматических MAE/MFE по свечам биржи; визуализаций мало; Trade Replay невозможен.
- **Тинькофф «Аналитика портфеля».** Бесплатно для клиентов, не нужно настраивать, но: только Тинькофф, без MAE/MFE, без Optimal f / SQN, без Replay, без эвристик. Это другой класс продукта (агрегат, не журнал).
- **TraderMake.Money** (333 ₽/мес). Большое сообщество, сотни виджетов, но фокус на крипту; поддержка MOEX/Тинькофф слабая, MAE/MFE — ручной.
- **Tradary** (333 ₽/мес). Покрытие брокеров РФ-фонда — лучшее на рынке, но UI устаревший, аналитика поверхностная, нет MAE/MFE из свечей, нет AI.
- **Tradersdiaries.com.** Бесплатный, известный, но технологически устарел; без MOEX, без современной аналитики.
- **TradeZella / Tradervue / Edgewonk** (15–50 $/мес). Best-in-class по глубине AI и Replay, но: чужие биржи, нет российских свечей, цена в долларах, санкционные риски доступа.
- **Smart-Lab «Журнал сделок».** Полу-форум, не инструмент. Площадка обсуждений, но не аналитический движок.

**What it costs them:**
- 3–6 часов в неделю на ведение Excel-журнала вручную (если ведут вообще).
- Не пойманная системная ошибка: средний MAE убыточных сделок в ~1,5× дальше стопа — стоп ставится слишком далеко. Каждый месяц это конкретные рубли.
- Перенос риска не там: интуитивный Optimal f часто 2–3× выше оптимального → геометрическое разрушение депозита.
- Невозможность сравнить свой квартал с прошлым: данных нет, расчёта нет, базы нет.
- Эмоциональная цена: «я не знаю, где я теряю» — главная фраза персоны P1.

**Emotional tension:** Трейдер чувствует, что у него есть «edge», но не может его доказать самому себе. Любой убыточный месяц возвращает в сомнение. Записать = признать; не записать = оставить себе люфт оправданий. Журнал — это не таблица, это позиция «я согласен видеть себя честно». МААТТ это уважение к тем, кто на эту позицию вышел.

## Differentiation

**Key differentiators (по убыванию защищённости):**
1. **Автоматический MAE/MFE из свечей MOEX ISS.** В России такой автомат не делает никто. Считается из минутных свечей биржи, не из реквоутов брокера, не вручную.
2. **Trade Replay со свечами MOEX.** Свечи вокруг входа/выхода + маркеры stop/take/entry/exit на одной шкале. В РФ — ни у кого.
3. **Серьёзная математика по первоисточникам.** Optimal f (Ralph Vince), SQN (Van Tharp), Sortino, Calmar, Ulcer, K-Ratio, Sterling, Omega, Sharpe, Risk of Ruin аналитически + Monte Carlo 10 000. Не Excel-шаблоны, не приблизительные пересчёты.
4. **РФ-стек регистрации.** OAuth Яндекс / Сбер ID / Тинькофф ID. Никаких Google/Apple-провайдеров как обязательных.
5. **152-ФЗ-ready.** Хостинг в РФ (Yandex Cloud), 30-дневная пауза перед анонимизацией, чёткий privacy contract.
6. **Цена в рублях.** 399 ₽/мес — фиксированно, без привязки к курсу доллара.
7. **Editorial-tone лендинга.** Спокойный профи, не «продавец курсов». Tone-shift в индустрии, где конкуренты по-прежнему говорят «AI-powered next-gen» и «грааль системности».

**How we do it differently:**
- MAE/MFE считаем по биржевым свечам через MOEX ISS API, не по сделочной ленте брокера. Это позволяет показать пользователю реальные экстремумы внутри жизни сделки, а не аппроксимацию.
- Тинькофф Invest API (read-only) + 60-секундный scheduler + FIFO-учёт + дедупликация. Для остальных брокеров — CSV/Excel-импорт (Финам/БКС нативно — в Q2/Q3 2026).
- Эвристики — детерминированные правила, которые трейдер может прочитать в документации и оспорить. Не deep learning, не «магический ИИ».
- AI-разбор позиционируется как «скоро», а не как hero-фича. Сначала запись, потом метрики, потом AI — в таком порядке.

**Why that's better:**
- Edge ratio (MAE/MFE) — основа оптимизации стопов и тейков; считать его руками на 200 сделках за месяц невозможно.
- Optimal f / SQN — это не «доп-метрики», это то, что отделяет трейдинг от ставок. Если их нет в журнале, журнал не закрывает свою главную задачу.
- Детерминированные правила, в отличие от ML-чёрного ящика, не обещают предсказать, а показывают, что нарушено относительно ваших же критериев.

- «Устал от Excel и ручного ввода.»
- «Доверяю Винсу и Тарпу больше, чем „трейдер-блогерам“.»
- «70 % результата — это дисциплина, а не сигналы.»
- «Я не доверяю западным сервисам — санкции, не работают, дорого, нет рублей.»

| **«У Тинькофф „Аналитика“ бесплатно.»** | У брокера нет MAE/MFE из свечей, нет Optimal f / SQN, нет Trade Replay, нет эвристик. Это разный продукт — у них агрегат портфеля, у нас инструмент для разбора каждой сделки. |

## Switching Dynamics

**Push (что выталкивает с текущего решения):**
- Из Excel: ручной ввод сорвался на 3-й месяц; журнал валяется незаполненный; нет MAE/MFE.
- Из Тинькофф «Аналитики»: «вижу P&L, не вижу почему теряю».
- Из «никакого журнала»: подряд два убыточных месяца → ощущение «я хаотично торгую».
- Из TradeZella/Edgewonk: цена в долларах, санкционный риск доступа, нет MOEX-свечей.
- Из TraderMake: «у меня фондовый, а у них фокус на крипту».

**Pull (что притягивает к МААТТ):**
- MAE/MFE автоматически из свечей MOEX — единственный сервис в РФ.
- Trade Replay — увидеть свою худшую сделку с маркерами stop/take/exit.
- Optimal f / SQN / Risk of Ruin — настоящие формулы.
- РФ-стек: рубли, Тинькофф ID, 152-ФЗ.
- Editorial-tone лендинга: «без AI-hype, без революций, без эмодзи».
- Подключить Тинькофф через API или загрузить CSV — первая статистика через 2 минуты.

**Habit (что нужно сформировать у пользователя):**
- Открывать дашборд раз в неделю (квартал к кварталу, а не сделка к сделке).
- Просматривать Trade Replay худшей сделки недели.
- Раз в месяц смотреть Optimal f / SQN — не уехал ли в перегрев.
- Не редактировать журнал «задним числом» — запись как факт, не как нарратив.

**Anxiety (что тормозит переход):**
- «Дадут ли мой токен Тинькофф нормально работать?» — снимаем явным указанием на read-only.
- «Что с моими данными?» — снимаем явным 152-ФЗ-блоком, Yandex Cloud, 30-day delete.
- «Ещё одна подписка не нужна.» — снимаем Free-планом до 50 сделок и 21-дневным Pro-trial без карты.
- «Меня заставят в Excel импортировать.» — снимаем явным «Тинькофф API нативно».
- «Это очередной AI-сервис с пустыми обещаниями.» — снимаем editorial-tone и бейджем «AI-разбор · скоро» вместо «AI-powered now».
- «Я не математик.» — снимаем глоссарием на лендинге (раздел 03 «Метрики», inline-explainers).

**Glossary (термины оставляем как есть, объясняем неочевидное):**

| Term | Meaning |
|---|---|
| **MAE** | Maximum Adverse Excursion — насколько глубоко цена уходила против сделки внутри её жизни. Из минутных свечей биржи. Помогает понять, не стоит ли стоп слишком далеко. |
| **MFE** | Maximum Favorable Excursion — насколько далеко цена уходила в сторону сделки. Подсказывает, не закрываете ли тейк слишком рано. |
| **Optimal f** | Оптимальная доля капитала на сделку по Ральфу Винсу. Доля, при которой геометрический рост портфеля максимален. Выше — перерасход риска (геометрия разрушает депозит), ниже — упускаемый рост. |
| **SQN** | System Quality Number (Ван Тарп) — √N × (среднее R / σ R). < 1,6 — система плохая; 2,0–2,5 — средняя; > 3,0 — отличная. Считается на закрытых сделках, не на бэктесте. |
| **R / R-multiple** | Размер выигрыша/проигрыша в единицах риска. Сделка с R = +2 означает: заработано 2× от начального риска позиции. |
| **R-Expectancy** | Среднее R-multiple на сделку. Положительный — стратегия в плюсе на длинной дистанции, отрицательный — наоборот. |
| **Profit Factor** | Сумма прибылей / сумма убытков. > 1 — стратегия зарабатывает; < 1 — теряет. |
| **Z-Score** | Значимость серий выигрышей/проигрышей. Подсказывает, есть ли в полосах паттерн или это шум. |
| **Sortino Ratio** | Доходность с поправкой только на downside-волатильность. Точнее Sharpe, потому что «волатильность вверх» — не риск. |
| **Calmar Ratio** | CAGR / Max Drawdown. Сколько годовой доходности на единицу макс. просадки. |
| **Recovery Factor** | Чистая прибыль / Max Drawdown. Скорость восстановления. |
| **Risk of Ruin** | Вероятность потерять 20 % / 50 % депозита при текущей win rate и среднем R. Считается аналитически по Винсу + подтверждается Monte Carlo. |
| **Monte Carlo 10 000** | 10 000 симуляций перестановки сделок — worst-case 5 % сценариев. |
| **Tail Ratio** | P95 win / |P05 loss|. Насколько «толстый» правый хвост по сравнению с левым. |
| **GHPR** | Geometric Holding Period Return — геометрическая доходность за период удержания. |
| **Post-Exit** | Что было со ценой после выхода — потенциальная прибыль/убыток, оставленные на столе. |
| **Edge Ratio** | Производное от MAE/MFE: насколько чаще ваша система получает MFE > MAE. Главный sanity-check сетапа. |
| **FIFO** | First-In-First-Out учёт партий по позиции — стандарт для журналов сделок. |

**Champions glossary (для секции «Дисциплина чемпионов» — Хеb-3 спецификации):**

## Brand Voice

**Archetypes:** Sage + Craftsman + Mentor. Никакого Hero / Outlaw / Jester.

**Tone:** спокойный профи, editorial, confident. Уважение к читателю — он умный, объяснять «как ребёнку» оскорбительно. Минимум прилагательных, максимум фактов и цифр. Юмор допустим, но сдержанный (не мемы).

**Style:** утверждение, не призыв. Короткие предложения. Точек больше, чем запятых. Цифры обнажены (399, не «триста девяносто девять»). Стремимся к 30–40 знакам в lede для editorial-вёрстки. Hyphen — em-dash «—», не дефис. Никаких эмодзи, восклицательных знаков, «🚀», «✨».

**Personality:** Sage — знание из первоисточников (Винс, Тарп, Шарп, Сортино, Калмар; Ливермор, Дарвас, Минервини); не объясняет известное (R, FIFO, win rate), объясняет неочевидное (Optimal f, SQN, MAE/MFE). Craftsman — ремесленник записи; «партитура», «фиксация», «свидетельство». Mentor — без снисхождения; «если узнаёшь себя — это тебе», без давления.

**Eight voice rules (из spec, §4.1):**
1. Утверждение, не призыв.
2. Цифры обнажены.
3. Метафоры из книг и спорта, не из ИТ.
4. Короткие предложения. Точек больше, чем запятых.
5. Не объясняем известное (R, FIFO, win rate).
6. Объясняем неочевидное (Optimal f, SQN, MAE/MFE).
7. Никаких emoji, «!», «🚀», «✨». Дефис у нас — «—».
8. Безличный или 2-е pl («вы»). «Я» — никогда. «Ты» — только в pull-quote и audience-checklist.

**Big idea (sample H1-direction, не финал):**
«Запись делает трейдера. / Что записано — то измерено.»
Tone-shift с «техническая платформа» → «спокойное утверждение о ремесле». Сам факт регулярной записи отделяет трейдера от игрока — до всяких метрик и ИИ.
