## 🏦 Структура комиссий

При совершении сделки списываются комиссии от **трёх участников**:

### 1. Биржевой сбор (MOEX)
Взимается биржей за организацию торгов.

### 2. Клиринговый сбор (НКЦ)
Взимается клиринговым центром за расчёты.

### 3. Брокерская комиссия
Взимается брокером за обслуживание.

## 📊 Фондовый рынок (Акции)

### Биржевые сборы:

| Режим торгов | Сбор | Описание |
|--------------|------|----------|
| Т+1 (TQBR) | 0.003% | Основной режим акций |
| Т+0 | 0.01% | Режим "сегодня" |

### Пример (покупка акций на 100,000₽):
```
Биржевой сбор: 100,000 × 0.003% = 3₽
Брокерская (Тинькофф): 100,000 × 0.05% = 50₽
ИТОГО: ~53₽
```

## 💳 Маржинальное кредитование (Margin Fee)

### Что это такое
**Margin Fee** — плата за использование заёмных средств (плеча) при торговле.

### Когда списывается:
- Ежедневно за каждый день удержания позиции с плечом
- Или единоразово при закрытии короткой позиции

### Размер:
| Брокер | Ставка |
|--------|--------|
| Тинькофф | ~15-25% годовых |
| БКС | ~15-20% годовых |
| Сбер | ~16-22% годовых |

### Расчёт:

```
Ежедневная плата = Сумма_заёма × (Годовая_ставка / 365)
```

**Пример:**
```
Заёмные средства: 100,000₽
Годовая ставка: 20%
Дней удержания: 30

Margin Fee = 100,000 × (0.20 / 365) × 30 = 1,644₽
```

### В Tinkoff API:

Margin Fee приходит как отдельная операция:
```
OPERATION_TYPE_MARGIN_FEE
```

## 🔧 Service Fee (Сервисный сбор)

### Что это такое
Дополнительные сборы за определённые услуги:
- Обслуживание счёта
- Хранение бумаг
- Дополнительные сервисы

### В Tinkoff API:
```
OPERATION_TYPE_SERVICE_FEE
```

## 🧮 Примеры расчёта итоговых затрат

### Пример 1: Интрадей торговля акциями

```
Сделка: Купил SBER на 500,000₽, продал на 510,000₽

Комиссия на вход:
  Биржа: 500,000 × 0.003% = 15₽
  Брокер: 500,000 × 0.05% = 250₽

Комиссия на выход:
  Биржа: 510,000 × 0.003% = 15.3₽
  Брокер: 510,000 × 0.05% = 255₽

Gross PnL: 510,000 - 500,000 = 10,000₽
Total Commission: 15 + 250 + 15.3 + 255 = 535.3₽
Net PnL: 10,000 - 535.3 = 9,464.7₽
```

### Пример 2: Фьючерсы с плечом (30 дней)

```
Сделка: LONG 100 контрактов Si
Использовано ГО: 1,500,000₽
Заёмные средства: 500,000₽

Комиссия на вход:
  Биржа + клиринг: 100 × 0.75₽ = 75₽
  Брокер: 100 × 2₽ = 200₽

Комиссия на выход:
  То же самое: 275₽

Margin Fee (30 дней):
  500,000 × (0.20 / 365) × 30 = 822₽

Gross PnL: (91000 - 90000) × 100 × 1 = 100,000₽
Total Commission: 275 + 275 + 822 = 1,372₽
Net PnL: 100,000 - 1,372 = 98,628₽
```

### Пример 3: Активный скальпинг (100 сделок/день)

```
Инструмент: Si
Средний объём сделки: 10 контрактов
Сделок в день: 100

Комиссия за день:
  Биржа + клиринг: 100 × 10 × 0.75₽ = 750₽
  Брокер: 100 × 10 × 0.5₽ = 500₽
  
Итого в день: 1,250₽
В месяц (22 торговых дня): 27,500₽
```

## ⚠️ Скрытые расходы

### 1. Спред
Разница между bid и ask съедает часть прибыли.

### 2. Проскальзывание
При рыночных ордерах цена исполнения может быть хуже.

### 3. НДС
На некоторые комиссии начисляется НДС (20%).

### 4. Конвертация валюты
При торговле валютными инструментами.

## 📊 Влияние комиссий на результат

### Для скальпера:
Если средняя прибыль со сделки 0.1%, а комиссия 0.05% туда и обратно:
```
Реальная прибыль = 0.1% - 0.1% (комиссии) = 0%
```
**Комиссии съедают всю прибыль!**

### Для свинг-трейдера:
Если средняя прибыль со сделки 5%, а комиссия 0.1%:
```
Реальная прибыль = 5% - 0.1% = 4.9%
```
Комиссии минимально влияют.

## 🔑 Рекомендации по оптимизации

1. **Выбирайте подходящий тариф**
   - Для активной торговли — "Трейдер"
   - Для инвестиций — "Инвестор"

2. **Избегайте мелких сделок**
   - Минимальная комиссия может быть выше процентной

3. **Консолидируйте ордера**
   - Лучше 1 ордер на 100 лотов, чем 100 ордеров по 1 лоту

4. **Следите за Margin Fee**
   - Закрывайте маржинальные позиции вовремя

5. **Используйте лимитные ордера**
   - Меньше проскальзывание

## 📝 Учёт комиссий в трейдинг-журнале

### Где брать данные:
1. **Из операций Tinkoff API** — поле `childOperations` с типом `*_FEE`
2. **Из отчёта брокера** — детальная разбивка по сборам
3. **Из выписки** — итоговые суммы за период

### Формула Net PnL:
```
Net PnL = Gross PnL - Broker_Fee - Exchange_Fee - Margin_Fee - Service_Fee
```

### Что отслеживать:
- [ ] Брокерская комиссия за сделку
- [ ] Биржевой сбор
- [ ] Margin Fee (если используется плечо)
- [ ] Service Fee
- [ ] Налоги (НДФЛ 13%)
