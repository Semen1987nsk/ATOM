## 🎯 Основные понятия

### Фьючерс
**Фьючерс** — это стандартизированный биржевой контракт на покупку/продажу базового актива в определённую дату в будущем по заранее оговорённой цене.

### Базовый актив
Актив, на который заключён контракт:
- Валюта (USD/RUB, EUR/RUB)
- Акции (Сбербанк, Газпром)
- Индексы (РТС, МосБиржи)
- Товары (нефть, золото)
- Иностранные акции (Alibaba, Tesla)

### Экспирация
Дата исполнения контракта. После экспирации контракт прекращает существование.

## 💰 Гарантийное обеспечение (ГО)

### Что такое ГО
**Гарантийное обеспечение** — это залог, который должен находиться на счёте для открытия и удержания позиции.

### Виды ГО:
| Вид | Описание |
|-----|----------|
| **Начальная маржа (IM)** | Минимум для открытия позиции |
| **Поддерживающая маржа (MM)** | Минимум для удержания позиции |

### Пример:
```
Фьючерс Si:
- Начальная маржа: 15,000₽ за 1 контракт
- Поддерживающая маржа: 12,000₽ за 1 контракт

Чтобы купить 10 контрактов нужно:
ГО = 10 × 15,000 = 150,000₽
```

### Маржин-колл
Если баланс падает ниже поддерживающей маржи — брокер принудительно закрывает позицию.

## 🔄 Вариационная маржа

### Определение
**Вариационная маржа (ВМ)** — ежедневное изменение стоимости позиции, которое списывается или начисляется на счёт по результатам клиринга.

### Формула расчёта

```
ВМ = (Текущая_цена - Предыдущая_расчётная_цена) × Количество × point_value

где:
point_value = STEPPRICE / MINSTEP
```

### Для LONG позиции:
- Цена выросла → ВМ положительная (прибыль)
- Цена упала → ВМ отрицательная (убыток)

### Для SHORT позиции:
- Цена упала → ВМ положительная (прибыль)
- Цена выросла → ВМ отрицательная (убыток)

## ⏰ Расписание клирингов

### Основная сессия (10:00-18:50)

| Время (МСК) | Событие |
|-------------|---------|
| 10:00 | Открытие торгов |
| 14:00-14:05 | **Дневной клиринг** |
| 14:05 | Возобновление торгов |
| 18:45 | Окончание основной сессии |
| 18:50-19:00 | **Вечерний клиринг** |

### Вечерняя сессия (19:00-23:50)

| Время (МСК) | Событие |
|-------------|---------|
| 19:00 | Открытие вечерней сессии |
| 23:50 | Закрытие торгов |

### Важно:
- **Во время клиринга торги приостановлены**
- ВМ начисляется/списывается в момент клиринга
- Расчётная цена определяется биржей на основе последних сделок

## 🧮 Примеры расчёта PnL

### Пример 1: Фьючерс Si (USD/RUB)

```
Параметры:
- MINSTEP = 1
- STEPPRICE = 1₽
- point_value = 1₽

Сделка:
- BUY 10 контрактов @ 90000
- SELL 10 контрактов @ 90500

Расчёт:
PnL = (90500 - 90000) × 10 × 1 = 500 × 10 × 1 = 5000₽
```

### Пример 2: Фьючерс BR (Brent)

```
Параметры:
- MINSTEP = 0.01
- STEPPRICE = 10₽ (примерно)
- point_value = 10 / 0.01 = 1000₽

Сделка:
- BUY 5 контрактов @ 75.50
- SELL 5 контрактов @ 76.20

Расчёт:
PnL = (76.20 - 75.50) × 5 × 1000 = 0.70 × 5 × 1000 = 3500₽
```

### Пример 3: Фьючерс RI (индекс РТС)

```
Параметры:
- MINSTEP = 10
- STEPPRICE = 2₽ (примерно, зависит от курса)
- point_value = 2 / 10 = 0.2₽

Сделка (SHORT):
- SELL 3 контракта @ 95000
- BUY 3 контракта @ 94500

Расчёт:
PnL = (95000 - 94500) × 3 × 0.2 = 500 × 3 × 0.2 = 300₽
```

## 📉 Как работает вариационная маржа

### Сценарий: Держим позицию несколько дней

```
День 1 (Понедельник):
- 10:00 BUY 10 Si @ 90000
- 14:00 (клиринг) расчётная цена = 90200
  → ВМ = (90200 - 90000) × 10 × 1 = +2000₽

- 19:00 (клиринг) расчётная цена = 90150
  → ВМ = (90150 - 90200) × 10 × 1 = -500₽

День 2 (Вторник):
- 14:00 (клиринг) расчётная цена = 90500
  → ВМ = (90500 - 90150) × 10 × 1 = +3500₽

- 15:00 SELL 10 Si @ 90600
  Остаток до клиринга = (90600 - 90500) × 10 = +1000₽

ИТОГО PnL:
+2000 - 500 + 3500 + 1000 = +6000₽

Проверка:
(90600 - 90000) × 10 × 1 = +6000₽ ✓
```

## ⚠️ Особенности учёта в Tinkoff API

### Операции вариационной маржи

В Tinkoff API вариационная маржа приходит как отдельные операции:

| Тип операции | Описание |
|--------------|----------|
| `OPERATION_TYPE_ACCRUING_VARMARGIN` | Начисление (прибыль) |
| `OPERATION_TYPE_WRITING_OFF_VARMARGIN` | Списание (убыток) |

### ВАЖНО: Нет привязки к инструменту!

```json
{
  "operationType": "OPERATION_TYPE_ACCRUING_VARMARGIN",
  "figi": "",  // ПУСТО! Нет FIGI
  "payment": {
    "units": "5000",
    "nano": 0
  },
  "date": "2024-01-15T14:02:00Z"
}
```

**Следствие:** Нельзя точно распределить ВМ по конкретным сделкам — только общая сумма по счёту.

### Как считать PnL для фьючерсов:

**Способ 1: По формуле (для отдельной сделки)**
```python
pnl = (exit_price - entry_price) * quantity * point_value
```

**Способ 2: По вариационной марже (для всего портфеля)**
```python
total_futures_pnl = sum(
    payment for op in operations 
    if op.type in ["ACCRUING_VARMARGIN", "WRITING_OFF_VARMARGIN"]
)
```

## 💸 Комиссии на срочном рынке

### Структура комиссий:

| Комиссия | Кто берёт | Примерный размер |
|----------|-----------|------------------|
| Биржевой сбор | MOEX | 0.5-5₽ за контракт |
| Клиринговый сбор | НКЦ | 0.5-1₽ за контракт |
| Брокерская | Брокер | 0.5-5₽ за контракт |

### Пример (Tinkoff, тариф "Инвестор"):
- Si: ~2₽ за контракт
- RI: ~3₽ за контракт
- BR: ~5₽ за контракт

### Margin Fee (плата за маржу):
Если используется плечо, брокер берёт ежедневную плату:
- Примерно 15-20% годовых от заёмных средств
- Списывается ежедневно

## 🔑 Ключевые риски

### 1. Маржин-колл
При недостаточном ГО позиция принудительно закрывается.

### 2. Гэпы
Цена может открыться далеко от закрытия предыдущего дня.

### 3. Экспирация
Контракт прекращает торговаться. Нужно роллировать позицию.

### 4. Плечо
Убыток может превысить первоначальный депозит!
