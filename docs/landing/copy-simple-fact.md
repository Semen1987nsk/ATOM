### Rationale

**Eyebrow.** Формат «Раздел NN — Title» — spec §6.2 норма; em-dash, не дефис (voice.md Rule 7). «Сам факт записи» — verbatim из spec §3.1 заголовка секции, сохраняем как уже утверждённую формулировку. Section number 00 явно помечен как placeholder Task 6 → актуализируется в Task 13 final pass (вероятно станет «Раздел 03» после уточнения IA: Header / Ticker / Hero / **SimpleFact** / Champions / Numbers / Manifest / 01-Trade Replay…).

**H2 «Дневник до всяких метрик.»** Это переплавка big idea на уровень секции. Hero уже несёт canonical: «Запись делает трейдера. / Что записано — то измерено.» (`copy-phase2-hero.md` Section 3 H1 Variant A). Воспроизводить любую из этих двух строк в H2 SimpleFact = смысловой повтор без приращения (та же ошибка, что отвергнута для Manifest cut-in в Section 7, см. `copy-phase2-hero.md` rationale для Manifest). H2 SimpleFact должен **уточнить** big idea: «дневник работает ДО метрик». Это и есть точное содержание Pillar A в секции (`messaging.md` row 4: «Чистый Pillar A в Mentor-регистре… пересказ работы дневника, которую читали Ливермор, Дарвас, Минервини. B и C тут лишние»). «До всяких метрик» — Mentor-формула из spec §2 («сам факт регулярной записи сделок отделяет трейдера от игрока — **до всяких метрик и ИИ**»). 5 слов — ниже формального коридора 6–10, но в editorial-вёрстке Fraunces SimpleFact даёт максимум дыхания (см. spec §3.1: «editorial-вёрстка с крупными цифрами 01/02/03»). Если редактор настаивает на 6+ слов — Alternate H2 (7 слов).

**H2 Alternate variant «Запись — это акт. Метрики — потом.»** 7 слов; явно соблюдает коридор; Craftsman-форма с двойным утверждением через em-dash. «Акт» — пересечение Craftsman (ремесленный акт записи) и Sage (philosophical акт согласия с собой; `.agents/product-marketing.md` § Problems / Emotional tension: «Записать = признать; не записать = оставить себе люфт оправданий. Журнал — это не таблица, это позиция „я согласен видеть себя честно"»). Выбор между Recommended и Alternate — решение редактора по плотности секции; функционально оба эквивалентны для Pillar A.

**Сохранение spec draft для 3 колонок (важно).** Spec draft в §3.1:

```
01 — Ты видишь сделки: Не помнишь — видишь. Память врёт. Запись — нет.
02 — Ты признаёшь ошибки: Не оправдываешь — признаёшь. Цифра не спорит.
03 — Ты сравниваешь себя с собой: Не с рынком — с собой. Квартал к кварталу.
```

— **уже прошёл voice-check насквозь**. Это не случайный черновик: формулировки «Память врёт. Запись — нет.» и «Цифра не спорит.» — verbatim из `.agents/product-marketing.md` § Customer Language (раздел подписан «*из черновика SimpleFactSection в spec*»). То есть spec-черновик SimpleFact уже является каноническим customer-language. Любая «переписка под voice» здесь — overcorrection: voice.md Rule 1 (утверждение, не призыв) соблюдён, Rule 2 (цифр нет — n/a), Rule 4 (короткие предложения: каждое body — 2–3 предложения по 2–4 слова), Rule 7 (нет emoji, нет «!»), Rule 8 («ты» — единственное разрешённое место по messaging.md row 4). Anti-vocabulary scan: «революцион / прорыв / уникальн / легко / быстро / AI-powered / нейросет / next-gen / грааль» — ноль попаданий. Favorite vocabulary: «видеть», «помнить» (через отрицание), «запись», «признать», «цифра», «сравнить», «квартал» — семь любимых слов в 30 словах body. Эта плотность недостижима без spec draft.

**Решение: spec draft принят 1:1 для bodies, не переписан.** Sub-headings оставлены spec-draft 1:1 («Ты видишь сделки», «Ты признаёшь ошибки», «Ты сравниваешь себя с собой»). Caption: добавлен monospace formatting `01 / 02 / 03` (mono per spec §3.1 «крупные цифры 01/02/03» — это JetBrains Mono в визуальной системе МААТТ). Прерывание этого черновика во имя «креативного рерайта» = ухудшение, не улучшение.

**Что в spec draft я НЕ менял — оправдание per column:**

- *Col 01.* «Не помнишь — видишь.» — Mentor-формула противопоставления через тире (voice.md Rule 4 + favorite vocabulary «видеть»). «Память врёт. Запись — нет.» — двойное утверждение, ритм-якорь, verbatim из customer-language. Любая попытка «развернуть» (например, «Память искажает. Запись фиксирует точно.») разрушает ритм и добавляет глагол-балласт. Оставляю verbatim.
- *Col 02.* «Не оправдываешь — признаёшь.» — противопоставление через тире, Mentor-форма к самому себе. «Цифра не спорит.» — Sage-формула, voice.md §Tone calibration #3 уже использует её как ритм-якорь в educational explainer для MAE/MFE. SimpleFact и MAE/MFE explainer перекликаются этой фразой — это сознательный editorial-callback на расстоянии 4 секций. Оставляю verbatim.
- *Col 03.* «Не с рынком — с собой.» — противопоставление через тире, ремесло (`.agents/product-marketing.md` § JTBD #3: «Сравнивать себя с собой. Квартал к кварталу: вырос Optimal f, упал ли SQN»). «Квартал к кварталу.» — verbatim JTBD-формула, 3 слова, замыкает ритм трёх колонок. Оставляю verbatim.

**Bridge phrase «Это всё, что нужно. Метрики и алгоритмы — уже сверху.»** Verbatim из spec §3.1 1-строки-связки. Функция — двойная:

1. **Замыкает Pillar A** («это всё, что нужно» = дневник в чистом виде, до техники).
2. **Готовит handoff к §5 Champions** через ключевой императив «уже сверху»: метрики/алгоритмы / автоматика — это надстройка над привычкой; великие трейдеры XX века (Champions) практиковали ту же запись **без** метрик и без алгоритмов — у них не было MAE из свечей и не было Optimal f, но был дневник. То есть «уже сверху» открывает Champions-секцию не лобовой mention'ом («и вот великие, кто так делал»), а **смысловым контекстом**: «дневник = базовая привычка; всё остальное надстраивается». Champions-карточки (Ливермор 1900-е, Дарвас 1950-е, Минервини 1980-е) автоматически заполнят это пустое место «привычка без алгоритмов» — каждый из шести вёл дневник до всякой автоматики (messaging.md row 5 §Pillar A proof points: «Хронологический диапазон 1900-е → 2020-е. Дисциплина записи переживает четыре технологические эпохи»).

Лобовой handoff («И вот те, кто это знал до нас») в Alternate bridge — функционально работает, но: (а) 13 слов выходят за коридор max 12 из задания; (б) более directly-narrative тон не вписывается в Mentor-к-себе регистр SimpleFact (вторая половина bridge переключает голос с «ты к себе» на «нас» — нарушение Rule 8 в bridge-phrase, который семантически принадлежит SimpleFact ещё, не Champions). Рекомендую spec-verbatim bridge.

**Bridge phrase typography note (handoff to Phase 3):** italic курсив + center-aligned + Fraunces italic 16–18pt + paper-tint фон или paper-rule (1 px ink-3 above bridge). Spec §3.1 не уточняет — но editorial-эталон для afterword/связок в `voice.md` §Tone calibration #2 показывает именно italic short statement с em-dash pacing.
