### Anchor framing suggestion

Не используем псевдо-социальные доказательства типа «60 % трейдеров на Pro» — у нас бета-период, цифры нет, Rule 2 (цифры обнажены) + voice anti-vocabulary запрещают выдумывать. Spec помечает бета-период честно.

Допустимый anchor — **временной**: «399 ₽ / мес» рядом микро-надпись `13 ₽ В ДЕНЬ` (mono caps 11px под ценой Pro). Это объективная декомпозиция, не давление. Закрывает объекцию «Дорого» из objection table product-marketing.md без эпитетов («всего», «целых»).

Альтернативный anchor — **годовой toggle** (cro-audit.md §6 recommendation #5). Если UI-бюджет позволяет: «Месяц · Год (−17 %)». При Year: «3 990 ₽ / год» + микро «332 ₽ в мес при оплате за год». Honest discount, editorial-tone. Рекомендация в Phase 3, не обязательная для копи-сдачи.

### Rationale

Frame H2 переход от «бесплатно до 50 сделок» (продажа цены) к «понять → изменить» (продажа JTBD-stages). Free и Pro перестают конкурировать как «бесплатное vs платное» (плохой anchor — мозг выбирает 0 ₽) и становятся «вижу проблему» vs «работаю с проблемой».

«AI-разбор каждой закрытой сделки» удалён из Pro features — это была главная voice/product lie (cro-audit.md issue #3 — H-impact). Заменён на «Эвристический разбор по 12 детерминированным правилам. AI-разбор — в roadmap.» Это правда из product-marketing.md и messaging.md row 12.

«21 день Pro в подарок» поднят из подвала в бейдж рядом с Pro-заголовком (cro-audit.md issue #5 — H-impact). Trust line под карточками теперь несёт более широкий risk-reversal (отмена / экспорт), а не только повтор trial.

«Календарный P&L» добавлен в Free — это уже работающая фича из product-marketing.md (use case «дни-убийцы»), пропущенная в текущем feature-list. Усиливает Free без перетягивания одеяла с Pro.

Pillar B ведущий + C secondary. Цифры обнажены: 50, 60 сек, 12, 5, 399, 21. Никаких «всего», «лишь», «впечатляющих».

### Rationale + A/B hypothesis

Variant A — Sage-доминанта, повтор canonical big idea «Запись делает трейдера». Работает лучше на warm-traffic с Smart-Lab / Pulse: аудитория уже прочитала весь лендинг, big idea зарезонировала — финальный повтор закрывает решение через утверждение.

Variant B — Craftsman-доминанта, обращение к ремеслу через конкретное время. Работает лучше на cold-traffic с поиска / anchor-link `#cta`: «три минуты» + «фоновая работа» снимают страх «обязательств», характерный для cold-intent.

**Метрика решения:** click на primary CTA + completion-rate регистрационной формы. Если форма коротка (≤3 поля), относим к финальному CTA; если длинная — оторвать от A/B по cro-audit.md рекомендации.

## Footer

### Tagline (главная строка в footer brand-блоке — Recommended)

**Решение: ЗАМЕНИТЬ.**

«Точно. Чисто. Честно.» — заменяем на: **«Запись. Учёт. Свидетельство.»**

> «Точно. Чисто. Честно.» — три однословных утверждения без конкретики, могло бы стоять под любым fintech (так и помечено в cro-audit.md trust-signals «Слабый — без конкретики»). Кроме того, «Чисто» в контексте финансовой темы может прочитываться как «отмывание / комплаенс» — двусмысленность не нужна.
>
> Новый якорь «Запись. Учёт. Свидетельство.» — три ключевых слова из любимого словаря voice.md, повторяющих big idea ремесла. Sage + Craftsman ритм. Те же три однословных утверждения, та же editorial-точка после каждого, но смысл прямо связан с продуктом.
>
> Если владелец продукта решит сохранить «Точно. Чисто. Честно.» — допустимо как fallback (нет анти-словарных нарушений). Рекомендация: заменить.
