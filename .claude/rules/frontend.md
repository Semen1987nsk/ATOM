# Frontend: Next.js 16, React 19, Tailwind v4, Recharts

- **Канон интерфейса** — `.business/product/CLAUDE.md`, `design-system.md` (Editorial Financial v3) и эталоны экранов `.business/product/feature-canon/`; скилл репо `nextjs-react19-server-patterns` — Server Components, Server Actions, Suspense.
- **Известные ошибки** — [docs/ERROR_CATALOG.md](../../docs/ERROR_CATALOG.md), диапазон ERR-301..306 (frontend, UX синхронизации, PowerShell).
- **Стиль** — [docs/CODING_CONVENTIONS.md](../../docs/CODING_CONVENTIONS.md).
- **Готово для правки интерфейса** — открыть в браузере на точном URL, пройти путь пользователя, снять скрин и сверить с `feature-canon/0X-*.md`; зелёные тесты без этого «готово» не дают (на добросовестности).
- `npm` — только из Git Bash.
