# Unit-экономика

> Скелет — гипотезы, не факты. Сверяем с реальностью каждый квартал.
> **Модель: Reverse-Trial 21 день → Free+ → Pro 399₽.** См. [`ADR-0005`](../tech/decisions/0005-reverse-trial-model.md), [`sales/pricing.md`](../sales/pricing.md).

## Trial (21 день, при регистрации)

### Прямые расходы за весь trial-период

- Anthropic API (cap **30 запросов** за 21 день): ≈ 40-50₽
- MOEX ISS API запросы для MAE/MFE (cap rate-limit per user): ≈ 5₽
- Yandex Cloud (compute + storage, 21 день): ≈ 25₽
- Email + push (Notify-провайдер, 7-8 сообщений за trial): ≈ 5₽

**Total COGS за trial: ≈ 75-85₽** (cap ~80₽).

### Payback

- При конверсии **8%** (целевая для reverse-trial): payback по trial = 80₽ / (8% × 399₽) = **2.5 trial-юзера на 1 платного × 80₽ = ~30₽** на каждого платного. **Окупается с первого месяца Pro.**
- При конверсии **3%** (низкая граница): payback ≈ 2.7 месяца Pro. Допустимо.
- При конверсии **<2%**: маржа Pro съедается. **Тригер для отката feature-flag `reverse_trial_v1_enabled`.**

## Free+ (после trial, навсегда)

### Прямые расходы на юзера в месяц

- Cloud + DB (хранение истории, замороженных PDF, токена): ≈ 20₽
- Email re-engagement (1-2/мес): ≈ 2₽
- UI-render замороженных виджетов (пренебрежимо)

**COGS Free+: ≈ 22-25₽/мес** (+10₽ vs текущего Free — за счёт хранения PDF-итогов trial и зашифрованного токена).

**0₽ дохода.** Free+ юзер платит виральностью (K-фактор + конверсия через decay архивных метрик: Optimal f / Sharpe устаревают за 2-3 месяца после downgrade).

### Условие виральной окупаемости

Free+ юзер окупается если приводит **1 платного за 6 месяцев** (на CAC-канал «партнёрка/виральность»). Целевой K-фактор виральности: **≥0.4**.

## Pro-план (399₽/мес)

### Доход
- ARPU: 399₽/мес
- LTV (при churn 6%/мес): 399 / 0.06 ≈ **6 650₽** на юзера

### Прямые расходы (на юзера в месяц)
- Yandex Cloud (compute / DB / storage): ≈ 30₽
- ЮKassa комиссия (3.5%): ≈ 14₽
- Anthropic API (если AI используется): ≈ 20-50₽ (зависит от частоты)
- Sentry / мониторинг: ≈ 5₽

**COGS: ≈ 70-100₽/мес**

### Gross Profit
- GP per user: 399 - 90 ≈ **309₽/мес**
- GP margin: ≈ **77%** (нормально для SaaS)

### CAC (гипотеза до запуска маркетинга)

| Канал | Ожидаемый CAC | Когда |
|---|---|---|
| Smart-Lab контент (виральный) | 0-100₽ | сразу |
| YouTube органика | 200-500₽ | через 6 мес |
| Партнёрка (20% MRR за 12 мес) | 957₽ ≈ 2.4 ARPU | 6+ мес |
| Платная реклама в Telegram | 1500-3000₽ | возможно |

### Payback period

- Smart-Lab: 0-1 мес
- YouTube: 1-2 мес
- Партнёрка: ≈ 3 мес (но получаем 12 мес выплат — всё равно выгодно)

## Запасные расчёты

### Если поднять цену до 590₽

- ARPU: 590₽ (+48%)
- GP: 590 - 100 = 490₽ (+58%)
- LTV (при том же churn 6%): 9 833₽ (+48%)

**Риск:** churn увеличится с 6% до 8-10%? Тогда LTV станет 5 900-7 375₽ — близко к нынешнему. Нужен А/B-тест.

### Воронка под цель Q3 2026 (1000 платных)

Целевая модель: **Reverse-Trial конверсия 7-10%** (бенчмарк Kyle Poyar / Notion).

| Сценарий | Конверсия | Регистраций для 1000 платных | COGS Free+ при стабилизации |
|---|---|---|---|
| Pessimistic | 4% | ~25 000 | 20 000 × 25₽ = **500 000₽/мес** |
| Realistic | 7% | ~14 000 | 11 000 × 25₽ = **275 000₽/мес** |
| Optimistic | 10% | ~10 000 | 7 500 × 25₽ = **190 000₽/мес** |

При reaching 1000 платных MRR ≈ 400 000₽ — реалистичный сценарий сходится (Free+ COGS ≤ 70% MRR).
