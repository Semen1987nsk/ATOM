# Уведомление РКН (форма Н-152)

> Скелет процесса. До запуска платных функций — обязательно.

## Что это

Согласно ст. 22 152-ФЗ оператор ПД обязан уведомить Роскомнадзор о начале обработки ПД. Форма — Н-152.

## Когда подавать

**До** начала фактической обработки ПД физических лиц на территории РФ. Сейчас Empirik юридически в серой зоне — есть пользователи, но нет уведомления. Это нужно закрыть **до платного запуска**.

## Где подавать

[`pd.rkn.gov.ru`](https://pd.rkn.gov.ru/) — портал Роскомнадзора.

## Что нужно для подачи

1. **Юридическое лицо** (ИП или ООО). Без юрлица невозможно подать.
2. **ОГРН** + **ИНН** + контактные данные оператора
3. **DPO**: ФИО, email, телефон
4. **Описание целей обработки** (см. `policy-versions.md` пункт 3)
5. **Категории ПД** (email, имя, IP, UA, торговые данные)
6. **Категории субъектов** (физлица — пользователи)
7. **Перечень действий** с ПД (сбор, хранение, использование, удаление)
8. **Меры безопасности** (шифрование, доступ по ролям, бэкапы и т.д.)
9. **Сроки обработки** (до отзыва согласия)
10. **Локализация** (Yandex Cloud / Selectel / VK Cloud — указать конкретно)

## Сроки рассмотрения

15-30 дней. Ответ:
- ✅ Внесён в реестр операторов ПД
- ❌ Запрос на доработку (исправляем и подаём заново)

## Что блокирует подачу сейчас

- [ ] Нет юрлица
- [ ] Не назначен DPO
- [ ] Нет финального хостинг-провайдера
- [ ] Юрист не утвердил формулировки

## Процесс на нашей стороне

1. Зарегистрировать ИП / ООО
2. Назначить DPO (приказом)
3. Развернуть прод на Yandex Cloud
4. Дать юристу `policy-versions.md` + `data-retention.md` для проверки
5. Заполнить форму Н-152 на портале
6. Дождаться ответа РКН
7. После внесения в реестр — публиковать в политике номер записи
