# compliance/ — 152-ФЗ, политика, удаление, РКН

⚠️ **Эта папка — обязательная остановка** перед любой задачей касающейся ПД (регистрация, профиль, экспорт, удаление, импорт сторонних данных).

## Карта папки

- `152-fz-status.md` — **ключевой файл**: статус 7 пунктов чеклиста + что закрыто
- `policy-versions.md` — версии политики конфиденциальности (v1, v2…)
- `rkn-notification.md` — уведомление РКН по форме Н-152
- `data-retention.md` — сроки хранения по 152-ФЗ vs 402-ФЗ vs 115-ФЗ

## Принципы

1. **Ничего не делаем без юриста для финального запуска.** Эта база — внутренний контекст для ответственной разработки. Финал — у юриста.
2. **Версионируем согласие** — в коде это `consent_text_version="v1"`. При смене текста — инкремент.
3. **Право на удаление — двухфазное** (request + 30 дней grace + finalize). См. ADR-0002.
4. **Платёжные документы храним 4 года** (402-ФЗ), даже после удаления аккаунта.

## Когда срабатывать

| Триггер в задаче | Что прочитать |
|---|---|
| Регистрация, согласие, чекбокс | `152-fz-status.md` |
| Удаление аккаунта, soft delete | `152-fz-status.md` + ADR-0002 (`tech/decisions/`) |
| Изменение политики | `policy-versions.md` |
| Уведомление в РКН | `rkn-notification.md` |
| Сроки хранения | `data-retention.md` |
| Экспорт ПД пользователю | `152-fz-status.md` (право доступа, ст. 14) |
