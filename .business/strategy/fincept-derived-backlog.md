# Fincept-derived backlog — что можно взять ПОЗЖЕ

> **Статус: PARKED. В MVP и текущий спринт НЕ берём ничего из этого.**
> Документ — память на будущее, чтобы не изучать Fincept заново и не соблазниться
> терминальными фичами раньше времени. Создан 2026-06-23 по итогам анализа
> репозитория [Fincept-Corporation/FinceptTerminal](https://github.com/Fincept-Corporation/FinceptTerminal)
> (open-source клон Bloomberg-терминала).

## Зачем это здесь

Fincept — **pre-trade / live терминал** институционального класса. Полистата —
**пост-трейд журнал** ритейла MOEX (см. [personas.md](../product/personas.md),
[competitive-landscape.md](./competitive-landscape.md)). Продукты перпендикулярны:
Fincept про «что купить» (вперёд), мы про «что уже сыграно» (назад). Поэтому
**0 из 14 доменов Fincept берём целиком** — любой тянет в журнал live/алго/
мульти-ассет/западную инфру, то есть расфокус. Ценность — лишь несколько
**отделяемых микро-приёмов**, и все они считаются на УЖЕ имеющихся данных
(закрытые сделки + минутные свечи MOEX ISS), без новых источников и тяжёлых либ.

**Принцип-якорь:** журнал должен остаться журналом. Берём приём, только если он
усиливает нарратив «где ты теряешь» и не требует live-фида/мульти-ассета/западных
данных.

## Очередь 1 — первый ПОСТ-релизный спринт (после MVP)

Малой кровью, на существующей инфраструктуре (MAE/MFE-свечи, AI-инсайты, дашборд).
Это расширения текущих блоков, НЕ новые продукты.

- [ ] **F1. Качество исполнения: slippage входа/выхода vs VWAP бара**
  - Ценность: показывает, что потеря не в сетапе, а в плохом исполнении.
  - Данные: те же минутные свечи MOEX ISS, что уже тянем для MAE/MFE — новых нет.
  - Усилие: **малое.** DoD: в карточке сделки строка «проскальзывание ≈ X% / Y₽ vs VWAP бара входа».
- [ ] **F2. Пост-трейд дисциплинарные уведомления** (из истории, НЕ live-цены)
  - Ценность: ловит оверторговинг / тильт / просадку винрейта сетапа.
  - Данные: закрытые сделки, ночной/после-синк job. Каналы: email (уже в стеке) + опц. Telegram.
  - Усилие: **малое.** DoD: ≥3 триггера («сделок больше нормы», «N убытков подряд», «винрейт сетапа просел») + дайджест на email.
  - ⚠️ Без real-time price-cross алертов, health-мониторинга, MCP, 15 каналов.
- [ ] **F3. Ретроспективная карта концентрации риска**
  - Ценность: «80% риска/PnL было в SBER» — закрывает слепую зону P1.
  - Данные: сами сделки, без ковариаций наперёд и мульти-ассета.
  - Усилие: **малое.** DoD: блок «доля реализованного PnL и задействованного капитала по тикеру/сетапу».

## Очередь 2 — v2 (когда вырастем)

- [ ] **F4. RU-новостная аннотация по тикеру сделки** — 1–2 заголовка MOEX/эмитента к моменту входа/выхода в Trade Replay. Не лента. Только RU-контекст.
- [ ] **F5. Корреляция одновременно открытых позиций** — факт из истории («GAZP+LKOH проседали синхронно»), не прогноз.
- [ ] **F6. Исторический VaR/CVaR по equity-кривой** — пара строк рядом с Sortino/Monte Carlo, на дневной кривой счёта. Без вол-поверхностей.
- [ ] **F7. Персонализация дашборда** — show/hide/reorder KPI-карточек, одна раскладка на юзера в JSON-профиле. БЕЗ drag-n-drop-сетки и реестра виджетов.
- [ ] **F8. «Оптимальный стоп по моей истории» / what-if** — пост-трейд аналитика на реальных сделках (частично уже в MAE/MFE + Trade Replay). НЕ бэктест абстрактной стратегии.
- [ ] **F9. Точечные импортёры брокеров РФ** (БКС/Сбер/Альфа) — узкий CSV/API-парсер в существующий слой импорта + опц. визард сопоставления колонок. НЕ обобщённый маппер на 100 коннекторов. *(пересекается с roadmap Q3 «Альфа/Сбер импорт»).*

## Сознательно МИМО (НЕ берём — фиксируем, чтобы не пересматривать)

Каждый пункт = структурный расфокус для пост-трейд журнала ритейла MOEX:

| Домен Fincept | Почему мимо |
|---|---|
| Алго / бэктест / Quant Lab / Alpha Arena | Исключённый каноном сегмент «алготрейдеры со своим бэктестом»; pre-trade |
| Деривативы / опционы / греки / вол-поверхности | Опционы вне обслуживания; P1 их не торгует |
| DCF / CFA-валюация / fundamentals-движок | Pre-trade инструмент инвестора; нужна SEC/РСБУ-фундаменталка которой нет |
| Portfolio-оптимизатор (Марковиц/эфф. граница) | Forward-аллокация, не журнал |
| AI-агенты buy/sell (Баффетт и Ко) | Рекомендации = инвестконсультирование, риск 152-ФЗ |
| Trading Engine: live-исполнение / крипта / paper | Live-роутинг = лицензируемая деятельность; крипта/форекс вне канона |
| Node Editor / Workflow Builder | Live-автоматизация + произвольный код = security/регуляторный кошмар |
| Морская/гео-разведка, Prediction Markets, alt-data, 100+ коннекторов, WebSocket | Глобальная pre-trade разведка по мульти-ассету; Polymarket недоступен резиденту РФ |
| Глобальные новости/макрокалендарь/government-порталы | Pre-trade шум для западных персон (берём максимум узкую RU-аннотацию — F4) |
| MCP-сервер / health-монитор / price-cross алерты / auto-update / 15 каналов | Live-инфра реального времени; auto-update бессмыслен для web-SaaS |
| Widget Canvas (drag-n-drop сетка live-виджетов) | Live-виджеты при 15-мин задержке бессмысленны; «пустой холст» против курируемого онбординга |

*(Согласуется с roadmap «Не делаем»: крипта, forex, опционы, алготрейдинг.)*

## Финальный вывод

«Брать из Fincept» как продукт — **не стоит**: это терминал, и любой его домен
целиком = расфокус при маленькой команде и тарифе 399₽. Реально полезны **3 приёма
(F1–F3)** в первый пост-релизный спринт и **6 зёрен (F4–F9)** в v2 — все строго
пост-трейд, на имеющихся данных. До закрытия MVP (Q2: ЮKassa/54-ФЗ, downgrade-job,
РКН, Yandex Cloud — см. [roadmap.md](./roadmap.md)) — **не трогаем ничего из этого.**
