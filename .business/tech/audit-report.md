# Аудит Empirik на 33 метрики

**Дата:** 2026-05-07
**Аудитор:** независимый senior review
**Объём:** ~28k строк Python + ~25k строк TS, 156 файлов
**Итоговая оценка:** **7,4 / 10** (взвешенно по важности)

## TL;DR

Empirik — сильный, добросовестно сделанный MVP с нетипично глубокой аналитикой и продуманной безопасностью. Код реально работает, формулы Винса/Тарпа реализованы по-настоящему, безопасность на уровне финтех-старта, дизайн вышел из cyberpunk-эстетики в спокойный продуктовый стиль уровня Linear/Vercel. Но: **позиционирование расщеплено** (бизнес-план — про крипту, код — про MOEX/Тинькофф), **компания юридически не готова к РФ-рынку** (152-ФЗ, ЦБ, локализация ПД), **нет тестов фронта и Е2Е**, **миграции БД незрелые**.

Ниша «РФ-фондовый дневник с серьёзной математикой» — пуста. При правильном go-to-market проект может за 12–18 месяцев занять её.

## Стратегические рекомендации

1. **Фокус: «MOEX-нативный AI-журнал для серьёзного ритейла»**. Не конкурировать с TraderMake в крипте.
2. **Hero-фичи**: MAE/MFE и Trade Replay. В РФ их **ни у кого** автоматически нет.
3. **Закрыть Финам/БКС/Альфа/Сбер за 2-3 месяца** — без этого 30% рынка пропадает для половины пользователей.
4. **Цена 399₽/мес заниженная**. Тестировать 590-790₽ для Pro и 199₽ для Lite.
5. **AI Insights — довести до уровня TradeZella**. У вас 12 эвристик уже отличный фундамент.
6. **Перед платным запуском** убрать «SOON» с Календаря P&L и Сетапов минимум.

## Что НЕ делать

- Не возвращаться к крипто-биржам в коде. Не размывать фокус.
- Не делать Bento Grid и Glassmorphism из спеки. Текущий direction (Linear/Stripe-style) лучше.
- Не строить нативные мобильные раньше PWA.
- Не запускать Corporate-тариф пока нет stable Pro.
