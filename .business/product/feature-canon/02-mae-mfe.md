# Эталон №2 — MAE/MFE анализ (автоматический из MOEX)

**Скриншот:** `empirik-mae-mfe-page.png`
**Код:** `frontend/src/app/analysis/mae-mfe/page.tsx` + `frontend/src/components/dashboard/MAEMFEAnalysisPanel.tsx`
**Backend:** `backend/analytics/mae_mfe.py` + `backend/market_service.py`

## Что это и почему важно

**MAE (Max Adverse Excursion)** — максимальное движение цены **против** позиции за время сделки.
**MFE (Max Favorable Excursion)** — максимальное движение **в сторону** позиции.

Считается **автоматически из свечей MOEX** в момент анализа. У нас это hero-фича — в РФ ни у одного конкурента нет автоматически (см. `competitive-landscape.md`).

## Группировка

Два таба:
1. **Теги (Стратегии)** — группа по `Trade.tags[]` (JSON)
2. **Сетапы** — группа по `Trade.setup_id`

Для каждой группы:
- Кол-во сделок
- Win rate
- Средний MAE %
- Средний MFE %
- Edge ratio (MFE/MAE)
- Quality score (composite)

## Период-фильтр

Стандартный для всего analysis-раздела:
- «Все» / 20 / 50 / 100 / 200 / custom (последние N сделок)
- ИЛИ «Всё время / Неделя / Месяц / 3 мес / Год»

## Ре-расчёт MAE/MFE

Кнопка `Пересчёт` запускает фоновый расчёт MAE/MFE для всех сделок (через `backend/analytics/mae_mfe.py`):
1. Для каждой сделки берутся свечи MOEX от `entry_at` до `exit_at`
2. MAE = min(low) для long / max(high) для short — относительно entry_price
3. Записывается в `Trade.mae_price`, `Trade.mfe_price`
4. UI показывает прогресс (если >100 сделок — фон, не блокирует)

## Empty / loading / error states

- **Empty:** «Нет данных MAE/MFE» + большая кнопка `⚡ Рассчитать MAE/MFE`
- **Loading:** Skeleton таблицы (5 строк × 6 колонок)
- **Error MOEX:** «Не удалось получить свечи для X тикеров — попробуйте позже» (не падаем, показываем что есть)

## Поведение

- **Сортировка:** по умолчанию по quality score (по убыванию). Кликом — по любой колонке.
- **Поиск:** real-time по тегу/сетапу
- **Hover на строке:** не скрытно показывать tooltip с пояснением метрики (для новичков)
- **Click на строку:** drill-down — список сделок этой группы (модалка или sub-page)

## Что копировать в новые analysis-страницы

1. **Идентичный header**: title (28-32px) + 1-2 строки описания (16px slate)
2. **Tabs паттерн**: пилюли с иконками, активная — accent fill, остальные — outline
3. **Period filter**: тот же набор кнопок «20 / 50 / 100 / 200» + period dropdown
4. **Кнопка `Пересчёт`** — справа, secondary (outline), `🔄` иконка
5. **Таблица группировок**: monospace для чисел, цвет PnL по семантике, hover-row подсветка `surface-2`
6. **Recommendations внизу** — карточка с иконкой и текстом

## Что НЕ делать

- ❌ Новые цвета для разных тегов (random palette) — все теги индиго
- ❌ Pie-chart распределения (графики не лезут в плотность таблицы)
- ❌ Перегружать таблицу 10+ колонками — максимум 6-7
- ❌ Автозапуск пересчёта при каждом заходе — только по кнопке (это тяжёлая операция MOEX)
