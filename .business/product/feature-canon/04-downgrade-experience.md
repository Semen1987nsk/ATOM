# Эталон №4 — Downgrade experience (Trial → Free+)

**Контекст:** Reverse-Trial 21d → Free+ — см. [`ADR-0005`](../../tech/decisions/0005-reverse-trial-model.md).
**Скриншот:** *[TODO: добавить после реализации компонентов]*
**Код:** `frontend/src/components/FrozenFeatureBadge.tsx` (создать), `frontend/src/app/dashboard/page.tsx` (баннер trial-countdown).

## Принцип

**«Заморожено, не удалено».** Все Pro-фичи остаются визуально видимыми на Free+ как архив. Никакого скрытия, никаких пустых блоков. Видимое прошлое работает на loss aversion → upgrade.

Запрещено: модальные окна «Купи Pro!», всплывающие скидки, агрессивные CTA. Тон Empirik — спокойный, инструментальный (см. [`marketing/messaging.md`](../../marketing/messaging.md)).

## Визуальный язык замороженных виджетов

> ⚠️ **DS-правило (см. [`design-system.md`](../design-system.md)):** запрет эмодзи в кнопках/заголовках. Используем иконки **lucide-react** в UI; эмодзи допустимы только в email-тексте и документации, не в продакт-UI.

### `<FrozenFeatureBadge />` компонент

```
┌─────────────────────────────────┐
│  [Snowflake] Pro                │  ← бейдж в правом верхнем углу карточки
│                                 │
│   [Содержимое виджета как       │
│    архив, тёмно-серый фильтр,   │
│    без анимаций]                │
│                                 │
│   Последнее обновление:         │
│   31.05.2026 (trial)            │
│                                 │
│   [Возобновить → Pro 399₽]      │  ← inline-CTA, не модалка
└─────────────────────────────────┘
```

**Спецификация бейджа:**

- Размер: 11px caps, padding `4px 8px`, `--radius-sm` (6px)
- Цвет: `var(--info)` (`#3b82f6` из DS) с opacity `0.6` — приглушённый синий, не алармовый
- Иконка: `<Snowflake size={12} />` из lucide-react. **Эмодзи запрещены.**
- Tooltip on-hover: «Эта фича доступна на Pro. Твой архив за trial — навсегда сохранён»
- Hover на карточке: показать inline-CTA снизу с лёгкой подсветкой (без glow — см. DS)

### Фильтр содержимого

- Все числа в замороженной карточке: `opacity: 0.7`, `filter: grayscale(0.3)`
- Графики: монохром (один цвет slate-400)
- Sparkline / equity curve: dashed line вместо solid

### Inline-CTA (внутри карточки)

- Кнопка-ссылка: `text-sm`, цвет `var(--accent)`, без фонового заливания
- Текст: «Возобновить → Pro 399₽» / «Включить sync → Pro 399₽» / «Анализ новых сделок → Pro»
- Клик: ведёт прямо на `/pricing?from=frozen-{feature-name}` (UTM для аналитики триггеров)

| **Optimal f / SQN tile** | Архив + дата. Чувствителен к меняющемуся капиталу — устаревает за 2-3 мес. | «Live расчёт → Pro» |

| **AI Insights card** | 2 последних инсайта из trial | «Новые инсайты → Pro» |
| **Monte Carlo / Optimal f visualization** | PDF-кнопка «Отчёт trial-периода» | «Live расчёт → Pro» |
| **Trade Replay** на trial-сделке | Read-only свечи как обычно | — (это работает) |

| **Multi-account дропдаун** | Только текущий счёт + строка «+ Добавить (Pro)» | «До 5 счетов → Pro» |

## D+21 экран «Подарок за trial»

Появляется **один раз** при первом входе после downgrade. Non-blocking — можно закрыть.

```
┌────────────────────────────────────────────┐
│                                            │
│   [Gift icon]  Твой trial завершён         │
│                                            │
│   За 21 день мы проанализировали 27 сделок│
│   и нашли 3 паттерна:                      │
│                                            │
│   • Ты теряешь по пятницам после 14:00     │
│   • Стоп-лоссы срабатывают близко к MAE    │
│   • Optimal f = 0.18 (твой риск 0.25 завы.)│
│                                            │
│   [FileText icon] Скачать PDF-отчёт        │
│                                            │
│   Твоя история сделок сохранена.           │
│   Хочешь продолжить мониторинг?            │
│                                            │
│   [Возобновить Pro — 399₽/мес]  [Позже]    │
│                                            │
└────────────────────────────────────────────┘
```

**Спецификация компонента `<TrialEndedDialog />`:**

- Иконки: `<Gift />` для заголовка, `<FileText />` для PDF-кнопки (lucide-react, не эмодзи)
- Заголовок: 24px Geist Sans, weight 600 (без эмодзи, см. DS)
- Главная кнопка «Возобновить Pro» — `.btn-primary` indigo pill
- Вторичная «Позже» — `.btn-ghost`
- PDF-кнопка — `.btn-secondary` с иконкой слева
- Кнопка «Скачать PDF» — главное вторичное действие. Лимит не сбрасывается при закрытии экрана (PDF остаётся доступным навсегда в профиле через `/profile/trial-report`).
- «Позже» закрывает экран, повторно не открывается (флаг `subscription.trial_summary_shown = True`).
- AI-инсайты в экране — реальные, не выдуманные. Если найдено 0 паттернов — показываем «Мы не нашли явных проблем — это хорошо. Продолжай вести журнал на Free+».

### D+28 (re-engagement через неделю)

> **Тема:** За эту неделю AI перестал отслеживать 3 паттерна
>
> На trial мы находили закономерности в твоих сделках. На Free+ AI остановлен.
>
> Если бы он работал на этой неделе — вот что он мог бы найти на твоих 8 новых сделках:
>
> *[teaser: «Probable: revenge-trade pattern after Tuesday loss»]*
>
> [Возобновить AI → Pro 399₽](https://empirik.io/pricing)

**Чего нельзя писать:**

- ❌ «Последний шанс!», «Скидка только сегодня!» — анти-паттерн.
- ❌ «Ты упустишь возможности» — guilt-trip не наш тон.
- ❌ Цифры конверсии других юзеров («87% возвращаются на Pro!») — манипуляция.

## Trial-countdown баннер в `/dashboard`

Показывается на D-7, D-3, D-1 (последние 7 / 3 / 1 дни trial).

```
┌──────────────────────────────────────────────────────────┐
│ ⏱ У тебя 3 дня Pro. История сохранится навсегда.        │
│                            [Подробнее] [Подключить Pro]  │
└──────────────────────────────────────────────────────────┘
```

- Цвет фона: `var(--accent-trial)` = тёмно-синий, не алармовый
- Non-dismissable на D-1 (но не модалка, занимает 48px)
- Клик «Подробнее» → секция в `/pricing` с разбором что заморозится

## Что копировать в другие пейволлы

1. **Бейдж `🧊 Pro` + inline-CTA** — единый паттерн для всех замороженных фич, не создавать вариантов.
2. **«Архив навсегда» — не «удалено»** — копирайт-принцип для любых cooldown/restriction-сценариев.
3. **Кнопка «Удалить токен» доступна всегда** (152-ФЗ право удаления). Не прятать за upgrade.
4. **UTM-параметры на CTA** (`?from=frozen-{feature}`) — для аналитики, какой триггер чаще конвертит.

## Что НЕ делать

- ❌ Модальные окна «Купи Pro» при клике на замороженный виджет — agresivно, разрушает доверие.
- ❌ Полностью скрывать Pro-фичи на Free+ — теряется loss aversion.
- ❌ Алармовые цвета (красный, оранжевый) для бейджей и баннеров — Empirik не AdSense.
- ❌ Counters обратного отсчёта в стиле «осталось 4:32:11» — анти-паттерн рассрочки.
- ❌ Препятствовать удалению API-токена — нарушение 152-ФЗ и тона.
- ❌ Сбрасывать историю trial при downgrade — главное обещание Reverse-Trial («твоя история сохранится»).
- ❌ Повторно показывать D+21 экран при следующих логинах — раздражает.
