# Эталон №3 — Trade Replay (свечи MOEX вокруг сделки)

**Скриншот:** `eqio-replay-realistic.png`
**Код:** `frontend/src/app/replay/...` + `backend/routers/replay.py` + `backend/market_service.py:get_candles()`

## Что это и почему важно

Берётся одна сделка → подгружаются свечи MOEX за окно «вход −1 час … выход +1 час» (или зависит от holding time) → отрисовывается линия цены с маркерами:
- 🟢 Вход (горизонтальная зелёная линия + точка пересечения с временем входа)
- 🔴 Выход (зелёная если профит, красная если убыток)
- ⚪ Stop Loss (пунктирная серая)
- ⚪ Take Profit (пунктирная серая)

В РФ нет ни у одного конкурента (см. `competitive-landscape.md`). Это hero-фича для маркетинга.

## Поведение

### Auto-interval

Backend сам выбирает разумный interval на основе holding time:
- < 30 мин → 1m свечи (полная плотность)
- 30 мин - 4 ч → 5m
- 4 ч - 1 день → 10m или 1h
- 1-7 дней → 1h
- 1-4 недели → 1d
- > 1 мес → 1d или 1w

UI позволяет переопределить через pills (Авто / 1m / 10m / 1h / 1d / 1w / 1mo).

### Окно вокруг сделки

`from = entry_at - holding_time × 0.2` (минимум 30 мин)
`till = exit_at + holding_time × 0.2` (минимум 30 мин)

То есть пользователь видит контекст до входа и после выхода.

### Маркеры

| Маркер | Цвет | Стиль |
|---|---|---|
| Вход | `--success` (если long) или `--danger` (short) | Точка + горизонтальная сплошная линия |
| Выход | `--success` (если PnL>0) или `--danger` (PnL<0) | Точка + горизонтальная сплошная |
| Stop Loss | `--text-tertiary` | Горизонтальная dashed |
| Take Profit | `--text-tertiary` | Горизонтальная dashed |

### Tooltip на hover свечи

`OHLC + Volume + время (MSK)`

## Empty / loading / error

- **Loading:** Skeleton chart (показывается пока ждём ISS)
- **No data:** «Свечи MOEX за этот период недоступны» (бывает на нерабочих днях)
- **Error:** «Не удалось получить свечи. Попробуйте другой интервал» + retry кнопка

## Что копировать в новые «график-страницы»

1. **Header:** иконка ←-back + тикер + бейдж направления (LONG/SHORT)
2. **Interval pills:** одинаковая последовательность 1m/10m/1h/1d/1w/1mo + Auto
3. **Цвета линий:** зелёный/красный по семантике, серый dashed для SL/TP
4. **Footer-бейджи:** Окно / Интервал / Свечей / Статус — единый формат

## Что НЕ делать

- ❌ Не использовать TradingView Widget (тяжёлый, чужой стиль, требует загрузки скриптов извне)
- ❌ Не показывать индикаторы (RSI, MACD) — это перегружает, юзер пришёл смотреть свою сделку, не делать ТА
- ❌ Не делать zoom/pan интерактивно — это сложно и ломается на mobile
- ❌ Не загружать candles на client-side в больших объёмах — батчевать на backend (см. `tech/decisions/0004-moex-rate-limit.md`)
