## Порядок

1. Env для разработки: `backend/.env` по образцу `backend/env.example`, `DEBUG=true`, ключи сгенерировать (команды — в образце). Проверить `git check-ignore -q backend/.env`.
2. Окружение backend на Python 3.11, как в CI:
   `uv venv -p 3.11 backend/.venv` и затем
   `uv pip install --system-certs -p backend/.venv/Scripts/python.exe -r backend/requirements.txt --extra-index-url https://opensource.tbank.ru/api/v4/projects/238/packages/pypi/simple --index-strategy unsafe-best-match`, затем `pytest pytest-asyncio`.
3. Тесты backend — приоритетный способ, около 7 минут на sqlite.
4. Frontend: `npm ci` (около 2 минут), `npm run -s typecheck`, `npm test`.

## Почему так

- Индекс T-Bank подписан Russian Trusted Root CA, которой нет в наборе uv: без `--system-certs` — `invalid peer certificate: UnknownIssuer`.
- `unsafe-best-match` нужен, потому что зависимости пакета брокера лежат и на PyPI, и в индексе T-Bank.
- CI гоняет тесты на Postgres и Redis; локально без Docker — sqlite, поэтому миграционные проверки на Postgres локально не повторяются.
