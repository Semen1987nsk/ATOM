# SEO-ядро для РФ

> Скелет. Расширить через Wordstat / Keys.so / Google Trends перед запуском.

## Высокочастотные (HF)

- торговый дневник
- дневник трейдера
- журнал сделок
- статистика трейдинга

## Средние (MF)

- торговый дневник онлайн
- дневник трейдера бесплатно
- статистика сделок MOEX
- журнал сделок Тинькофф
- анализ трейдинга

## Низкочастотные (LF) — где конверсия выше

- торговый дневник Optimal f
- расчёт MAE MFE автоматически
- журнал сделок с AI
- дневник трейдера фондовый рынок Россия
- Monte Carlo трейдинг
- SQN качество системы
- Винс трейдинг калькулятор

## Long-tail (для статей)

- как считать optimal f для трейдинга
- что такое sqn в трейдинге простыми словами
- mae mfe анализ как использовать
- журнал сделок excel или сервис
- какой дневник трейдера выбрать

## Что НЕ оптимизируем

- forex дневник
- crypto journal
- bitcoin trading log
- любые англоязычные запросы

## Технический SEO (must-have)

- [ ] sitemap.xml
- [ ] robots.txt с allow для блога
- [ ] schema.org разметка для тарифов и FAQ
- [ ] Open Graph для соцсетей
- [ ] meta description на каждой странице (сейчас есть только на /privacy)
- [ ] canonical URLs
