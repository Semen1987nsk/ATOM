# Реестр живых треков

Вход в папку. Сессия начинается отсюда: взять трек из «Свободных», вписать
себя в «ведёт» и дерево, перенести строку в «Активные»; при остановке —
обновить «чего ждёт». Заведён 28.09.2026 при переносе харнесса, класс В.

**Чего этот файл не печатает, чтобы не спорить с другими принтерами:**

- **Порядок работ** — его печатает `.business/strategy/roadmap.md`.
- **Свежесть треков** — её печатает `python ~/.claude/hooks/agent_runs.py --stale`
  по содержимому файла, а не по mtime. Дат касания здесь нет намеренно.
- **Что сделано по треку** — это внутри самого файла прогресса.

У активного трека клетки «Ведёт» и «Дерево» заполнены всегда — трек без
ведущего живёт в разделе «Свободные». Пустое «чего ждёт» значит «неизвестно,
заполнить при следующем касании», а не «ничего не ждёт».
